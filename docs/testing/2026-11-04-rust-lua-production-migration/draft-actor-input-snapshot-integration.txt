Draft integration checklist; not a completion claim.

The staged owners are exact ports of the native runtime loops. The scanner,
compiler, Boolean-table capture and update-factory drafts have not been compiled.
Apply only after the actor-setter checker reaches a verified terminal result and
the source boundary is archived for the next phase.

Place the implementation under rust_engine/actors/input_snapshot so the adapter
can inspect private actor metadata without exporting a generic compatibility API.
Reuse rust_engine::baked_program and the existing Rust input Frame/bindings;
reexport those two private input items without changing their algorithms.

Expose a production input-registry snapshot getter. Require that the private
"functions" map has actually been installed, and reject active dispatch exactly
as native input::functions does. Function values remain traced by that map.

Scene factories must reject ended scenes and gate playback, action capture,
hooks and trace logging. Inspect through one rooted native-stack window and
restore its original top on all exits. Root update functions explicitly while
compiling, including functions read from weak actor fields. Returned owners must
contain no VM values, functions, tables, roots or runtime owner.

Implement position readiness using the canonical Rust actor queue/effect owner
and the same raw override checks as native can_compile_actor_position. Preserve
the probe restriction and check the actual copied target. Spin history matters:
native retains its spin table after stopeffect. Do not reject visibility-only
units merely because a position setter is ineligible. The combined traversal's
Advance check has a different contract: no replay/probe requirement, but queues,
spin, non-none effects and rainbow must remain rejected.

Prepare the existing lifecycle plan during scene construction where native
prepare_live_updates runs. Extract the cold-plan/cache publication from advance
without changing the existing advance algorithm. Record native recurring and
model-texture job flags in that frozen plan; source callback jobs from it and
preserve wrapper/child order. Do not compile a replacement tree in a factory.
Factory calls after an invalidating operation must preserve native cache/None
behavior. Check current rate/hibernate/pause fields with the original typed
conversions, accounting for Rust's canonical SetUpdateRate representation.

Use the unmodified actor_input and actor_input_render tests/fixtures as controls:
real event streams, action order/f32 bits, shared scalar and mutable-byte cells,
dense aliased Boolean tables, copied/chained setters, reserved scheduler aliases,
strict eligibility and no authored execution on rejection. Exercise input-only
and combined owners after scene/runtime destruction and retained callbacks/GC.
Do not add actions or broaden the existing finite callback subset.

The normal song facade, legacy isolation, remaining reference/ownership work,
final normal application/rendering/downstream checks, graph/link evidence and
matched performance/memory measurements remain part of the unchanged objective.
