# Standards coverage and outstanding work

This crate is under development. No complete-conformance or competitive-speed
claim is made. The complete user scope is retained in PLAN.md.

| Requirement | Current evidence / remaining work |
| --- | --- |
| Independent package, workspace registration | Cargo manifest; no application dependency |
| Native bounded marker parsing | Zero-copy segments/scans; stuffing/restart/fill boundaries; every truncated prefix tested |
| Sequential Huffman SOF0/SOF1, 8/12-bit | Implemented; 25 libjpeg-turbo cases, exact coefficients/tables |
| Progressive Huffman SOF2, 8/12-bit | Implemented spectral selection and DC/AC refinement; 25 oracle cases exact; band order, partial progression, EOB/restart and Al=13 tests |
| Arithmetic SOF9/SOF10 | Sequential/progressive 8/12-bit decoding/encoding implemented: native Annex D coder, full 16-bit Annex F/G models, DAC/defaults, DC/AC refinement, custom bands/scripts, band history and restarts; 32 pinned decoder fixtures and external coefficient gates. Broader conformance/performance pending; see ARITHMETIC-VALIDATION.md and PROGRESSIVE-ENCODER-VALIDATION.md |
| Predictive lossless SOF3/SOF11, 2–16-bit | Native Huffman/arithmetic decoding and encoding: all seven predictors, Pt, row restarts, component sampling/scripts and bounded two-dimensional arithmetic contexts. Turbo gates: 4,628 decoder/4,448 encoder cases. JPEG XT: 3,240 arithmetic cases (857 direct streams; 2,383 with documented Pt header normalization), 45 additional pinned fixtures, all 4,448 Huffman output hashes unchanged. Reference setup/output limitations and remaining conformance work are in LOSSLESS-VALIDATION.md |
| Hierarchical SOF5/6/7/13/14/15, DHP/EXP | Decoder, direct frame writer and automatic native/shared source pyramids implemented: matching IDCT references, signed FDCT/Pt, partial progressive precision, rational sampling, K.5 reduction, final spatial corrections, metadata/ICC and bounded storage/output. Sequential DCT stages support 1..255 components; progressive stages retain 1..4. Prior 5,200 exact C/native encoder comparisons plus 560 source-pyramid cases and 216 generic-component hierarchies have C frame-data checks; C-input workarounds are explicit. Broader conformance remains pending. See HIERARCHICAL-VALIDATION.md and COMPONENT-VALIDATION.md |
| DNL, initially unknown SOF/DHP heights | Whole-input decoding and native encoding for all 13 frame processes: first-scan resolution before allocation, zero/provisional/redefined heights, completed DHP inference, strict adjacency/range/length checks and bounded output. 2,124 native DNL files and 336 independent C-authored input checks; original-header C matches are separated from known-header entropy comparisons. 26 pinned all-process regressions; see DNL-VALIDATION.md. Bounded interchange output streaming is implemented; incremental input remains pending |
| Abbreviated tables/image streams | Stateful B.4/B.5 DQT/DHT loading, caller-defined tables, direct table/image encoding and all 13 frame processes. SOI resets DAC/DRI; image definitions persist; metadata stays stream-local. Genuine Turbo persistent-object checks and separately labeled rare-process equivalent-interchange checks are recorded in ABBREVIATED-VALIDATION.md. Table-only output streaming is implemented; incremental input and paired abbreviated output streaming remain pending |
| Gray, YCbCr, RGB, CMYK, YCCK | Native planes, native CMYK/polarity, all five shared output conversions; 486 color comparisons plus 192 CMYK source/transform encoder cases; broader corpus pending |
| All legal sampling factors and scan layouts | Explicit sequential/progressive scripts, per-scan MCU bounds, common/fractional factors and separate scans up to 4x4 factors (including YCCK 4:1:0); 5,214 C/native scan-script comparisons and 128 randomized legal scripts. Independent conformance corpus still pending |
| Full component-count range | Sequential DCT and lossless decoding/encoding support 1..255; progressive DCT supports the normative 1..4. Native coefficient construction, generated/custom scan groups, distinct per-component quantizers, abbreviated output and source pyramids are implemented. Generic planes retain application-defined color meaning. 1,367 native-authored and 672 C-authored generic-component comparisons; see COMPONENT-VALIDATION.md |
| Restart intervals and sequence validation | Sequential/progressive implemented; external 8/12-bit fixtures, corruption and EOB boundary tests |
| Original coefficients, tables, metadata | Coefficients and quantizers retained; APPn/COM bytes borrowed with scan positions |
| JFIF/JFXX, Exif, Adobe, ICC assembly | Typed bounded views, Exif orientation/IFDs/thumbnails, zero-copy ICC assembly and profile writing through 255 chunks; 114 external matches plus 6 malformed ICC cases; caller uses original profile for color management |
| IDCT, chroma upsampling, color numerics | Q20 IDCT: sample error <=1 on initial 50 cases and official T.83 numeric data; EREF/DREF checks each cover 119,936 native coefficients with error <=1 quantized unit and explicit edge policies. Exact rational centered interpolation; 486 RGB/CMYK comparisons have observed RGB error <=3. Full acceptance-criteria audit and broader numerical gates remain open |
| Native configurable encoder | Native pixel/quality/precision/sampling controls and integer FDCT/quantization; 172 external coefficient matches; 132 float-FDCT/size/quality comparisons; broader validation/performance pending |
| Optimized Huffman, progressive encoding | Annex K length-limited tables; generated/custom spectral and DC/AC successive approximation scans for both entropy modes; partial progressions and Al=13. EOB aggregation, per-scan table optimization and measured performance remain open |
| Streaming and allocation limits | `StreamEncoder<W: Write>` writes all 13 interchange processes and table-only streams through bounded reusable staging; model/raster/pyramid preparation stays in memory. Short/interrupted/failed writes, output ceilings, metadata and 255 components are checked. 222 file-output comparisons include 42 IJG and 210 JPEG XT checks; explicit C-input copies/exclusions are recorded in STREAM-ENCODER-VALIDATION.md. Incremental input, paired abbreviated output and full allocator/peak accounting remain pending |
| Independent corpus and three C oracles | Configured libjpeg-turbo 3.2.1, IJG libjpeg 10 and mozjpeg 4.1.1 ordinary-process gates; JPEG XT rare-process observations. Official T.83 corpus: 20 images plus B1, exact independent coefficient/sample checks, native EREF/DREF gates and 186 externally checked native coefficient encodes. All 45 original numeric/stream files are retained unchanged. Full acceptance-criteria audits, missing official hierarchy streams and broader combinations remain open; see T83-VALIDATION.md and MOZJPEG-VALIDATION.md |
| Fuzzing and malformed corpus | Every Huffman/arithmetic fixture truncation; 4,000 Huffman and 7,000 arithmetic mutation smoke cases; invalid progression, quantizer/DAC changes, SOS order and restart tests; 128 valid randomized scan-script comparisons. Coverage-guided fuzzing pending |
