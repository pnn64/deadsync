# deadlib-lua-legacy-sys

Low level Lua, LuaJIT and Luau FFI bindings for [`deadlib-lua-legacy`](../README.md),
imported from the same local mlua checkout. The Rust crate name remains
`mlua_sys`, and `links = "lua"` is retained.

See the parent [`PROVENANCE.md`](../PROVENANCE.md) for the exact source revision
and package adaptations. The original FFI README is retained as
[`UPSTREAM-README.md`](UPSTREAM-README.md). Original MIT notices are preserved
in [`LICENSE`](LICENSE).
