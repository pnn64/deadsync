# deadlib-lua-legacy-derive

Procedural macros for [`deadlib-lua-legacy`](../README.md), imported from the same
local mlua checkout. The Rust crate name remains `mlua_derive`, and generated
code continues to refer to `::mlua`.

Use this through `deadlib-lua-legacy` with its `module` or `macros` feature. See the
parent [`PROVENANCE.md`](../PROVENANCE.md) for the exact source revision and
package adaptations. Original MIT notices are preserved in [`LICENSE`](LICENSE).
