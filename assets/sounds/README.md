`beat_tick.ogg` and `measure_tick.ogg` are copies of ITGmania's
[`Themes/_fallback/Sounds/GameplayAssist clap.ogg`](https://github.com/itgmania/itgmania/blob/8a3bf8884acdcb69363f7f0ea592138e398c71e4/Themes/_fallback/Sounds/GameplayAssist%20clap.ogg).
Both native metronome sound redirects point to that clap. Separate files preserve
the beat/measure sound slots and allow each to be overridden independently.
